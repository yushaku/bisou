# Brand artwork

Created with the built-in imagegen tool. `brand-heart.webp` is the transparent mark; `app-icon.webp` is the cream-backed install icon. Run `pnpm icons` to export the runtime assets. The wordmark remains live text in the app.

## Heart prompt

Use case: logo-brand. Create a single production logo symbol for Bisou, a private couples journal app. One simple upright symmetric heart, plump gently padded silhouette, warm coral-peach colored very fine matte felt fabric. Soft rounded lobes, a clear deep top notch and gently rounded bottom point. Understated handmade tactile depth, extremely subtle microfibre texture, softly illuminated from upper left with a slightly darker lower edge, no gloss. Warm intimate refined design, consistent with cream-and-peach soft-fabric UI. The heart alone centered and filling about 85% of a square canvas, fully visible, front view, no perspective tilt. Clean bold outer silhouette must remain recognizable at 16px favicon size; prioritize the silhouette over tiny detail. Real transparent alpha background everywhere outside the heart. No text, letters, initials, face, hands, characters, stitches, badges, frame, square tile, extra hearts or decorative objects. No cast shadow outside the silhouette. This is the final reusable standalone brand asset, not a mockup or presentation sheet.

## Install icon prompt

Input: the generated transparent heart. Opaque output.

Create the app-icon export of this exact Bisou heart logo. Preserve the heart's coral-peach felt material, shape and soft shading. Place it centered on a flat opaque warm ivory cream square background, color #f5efe5. The heart itself should occupy 62% of the square's width and about 56% of its height, centered horizontally and vertically: all heart pixels must sit inside the central safe circle of diameter 80% of canvas for Android maskable app icons. Background bleeds completely to all four edges. No rounded square container: the entire output is a full square and the operating system supplies the crop. No letters, no text, no border, no other elements, no extra shadow or halo. This is a production icon asset, not a mockup. Square 1024px output.
